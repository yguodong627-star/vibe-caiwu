# 细水账 · 本地个人财务与订阅管理器

导入支付宝 / 微信 / 银行导出的账单 CSV，自动找出“每周、每月、每年都会扣一次”的支出，按月看支出和分类、设预算、提前知道哪天要扣钱。
**纯前端、打开即用、无账号、无 API key、完全免费（没有 Pro / 授权码 / 条数限制）。数据只存在你浏览器的 IndexedDB 里，不上传。**

在线使用：<https://yguodong627-star.github.io/vibe-caiwu/>（也可以下载本仓库，直接双击 `index.html` 使用）

## 谁会用
- 想搞清楚“每个月到底有多少钱在悄悄自动扣”的上班族、自由职业者；
- 手里有支付宝/微信/银行账单，但不想把流水交给任何 App 或网站的人；
- 想要预算超支提示，又不想注册、不想联网的人。

## 典型场景
1. 年底想盘点订阅：导入一年的支付宝账单 → 看“年化订阅成本”，逐条确认/排除识别出的周期扣费，把不用的取消。
2. 月中想知道还能花多少：设月预算和分类预算，总览页实时显示进度，超支标红。
3. 想知道下周会扣什么钱：订阅页和总览页顶部有“将在 N 天后扣费”的页面内提醒。

## 解决什么问题
记账 App 要么要登录上传、要么把“订阅识别 / 预算 / 导出”放进付费档；网页版账单分析工具多数要上传文件。本工具所有解析都在本地完成，识别规则公开，并且每条识别结果都由你确认。

## 功能
- **导入**：支付宝（新版“电子客户回单”、旧版“交易记录明细”）、微信支付账单、招商银行流水、工商银行明细；GBK / UTF-8 自动识别；其他格式用“手动映射列”（指定日期/商户/金额/收支方向列、金额符号规则）。导入前有预览：笔数、金额、被排除的行及原因、无法解析的行；支付宝/微信还会与文件头自带的“支出 N 笔 X 元”核对。重复导入同一文件不会重复入账（同日同额多笔不会被误当重复）。
- **周期扣费识别（规则公开）**：同商户 → 金额在最近一笔 ±10%（至少 ¥1，可调）→ 相邻两笔相隔约一个周期（周±1天 / 月±5天按日历月，月末自动对齐 / 年±7天）→ 连续 ≥3 期（年付 ≥2 期，标“把握较低”）；金额有波动时月/周至少 4 期；允许链中缺 1 期；同额退款会先与原支出配对并排除。每条结果可查看依据，由你**确认或排除**。
- **月度支出与分类**：SVG 自绘近 12 个月柱状图（可点选月份）、分类占比、商户前 8；分类规则可编辑（关键词 + 顺序），手动改过的分类不会被覆盖。
- **预算**：总预算 + 分类预算；用到 80% 提醒，超出标红并在总览顶部提示。
- **订阅提醒**：到期前 1/3/7/14/30 天（可选）、今天扣费、已过预计日未见新扣款、疑似已停止。**只在打开页面时显示，关闭浏览器不会有任何提醒。**
- **年化订阅总成本**：已确认且未疑似停止的项目 × 周期（周×52、月×12、年×1，取最近一笔金额）。
- **导出 / 备份**：流水 CSV、订阅 CSV（UTF-8 BOM，Excel 可直接开）、完整备份 JSON；JSON 可“覆盖恢复”或“合并”。

## 口径（重要）
- 月支出 = 当月支出 − 当月**收到**的退款（退款算在收到那个月，所以退款当月可能出现分类为负）。
- 不计入：账单里的“不计收支/中性交易”（充值、提现、信用卡还款等）、交易关闭/失败的订单、你标记“不计入”的记录、普通收入（只在总览里作参考显示）。
- 所有金额用整数“分”计算，没有浮点误差。

## 已知限制（如实）
- 列名依据公开资料核对（支付宝、微信、招行、工行）。银行/平台可能改版；认不出请用手动映射。建设银行等其他银行没有核对到稳定的公开列名，需手动映射。
- 银行卡“快捷支付”的商户常显示为“待清算…专户”，查不出真实商户，这类记录不参与订阅识别。
- 支付宝/微信与银行流水会对同一笔消费各记一次，同时导入会重复，请用“账单范围”分开看。
- 只处理人民币，外币行会被跳过并提示。
- 识别是规律推测，不保证一定是订阅（房租、电费也会被识别，请自行确认/排除）；不足 3 期的月付不会被识别；年付至少需要 2 年数据。
- 微信“已全额退款”等状态依赖平台文案；若原支出行状态含退款但没有对应的退款行，会标“待核对”，需你判断。
- 数据在浏览器本地：清除浏览器数据、换设备都会丢，请定期导出备份；不支持多设备同步；关闭浏览器不会提醒。
- 调试：网址加 `?today=2026-10-18` 可固定“今天”（用于测试提醒）。

## 自测
`tests/gen_bills.py` 生成模拟账单（支付宝 GBK / 微信 / 招行 / 通用）和独立计算的期望值；`node tests/run-core.js` 校验解析、月度汇总、周期识别；`node tests/e2e.js` 用无头 Chrome 走完整流程（需要 playwright-core 与 Chrome）。
